# Egy360 Social Media Content Templates

## Content Strategy Overview

```
SOCIAL MEDIA FUNNEL:

Hook (3 sec) → Value (15-30 sec) → CTA → Link in Bio → Blog → Affiliate Sale
                                              ↓
                                        Email Signup → Nurture → Repeat Sales
```

**Platform Priority:**
1. **Instagram** - Primary (visual travel content)
2. **TikTok** - Secondary (viral potential, younger audience)
3. **Facebook** - Tertiary (groups, older demographic)
4. **YouTube** - Long-term (SEO, evergreen content)
5. **Pinterest** - Passive (travel inspiration boards)

## UTM Link Structure

**Always use UTM parameters for tracking:**

```
https://360egy.com/blog/best-pyramids-tours-cairo/?utm_source=instagram&utm_medium=social&utm_campaign=pyramids_post&utm_content=reel_jan15
```

**UTM Parameter Guide:**
| Parameter | Values |
|-----------|--------|
| utm_source | instagram, tiktok, facebook, youtube, pinterest |
| utm_medium | social, bio_link, story, reel, post |
| utm_campaign | pyramids_tours, cairo_hotels, luxor_guide, etc. |
| utm_content | specific post identifier (reel_jan15, carousel_1) |

**Use a link shortener:** Bitly, Rebrandly, or your own domain redirect

## Performance Tracking

### Weekly Metrics to Track

| Metric | Goal | Tool |
|--------|------|------|
| Followers gained | +100/week | Platform analytics |
| Engagement rate | 5%+ | Platform analytics |
| Link clicks | 50+/week | Bitly or UTM tracking |
| Website traffic from social | 200+/week | Google Analytics |

### Content Performance Review

**Keep doing** (high engagement):
- POV Reels with trending audio
- Carousel guides with save-worthy content
- Honest reviews and budget breakdowns

**Test more:**
- Different posting times
- Various hook styles
- New content formats (duets, stitches)

**Stop doing** (low engagement):
- Generic travel quotes
- Low-quality reposts
- Posts without clear CTAs
