# Egy360 - Egyptian Tourism Platform

## Overview
Egy360 is a comprehensive web-based platform designed to enhance the Egyptian tourism sector by connecting tourists with verified, safe, and licensed accommodations, transportation, tours, and travel information.

## Mission
To help both local and international tourists feel safe and comfortable while exploring Egypt's beautiful sites, while preventing scams and promoting legitimate tourism services.

## Features

### 🏨 Accommodation Search
- Integration with Booking.com and Expedia
- Verified safe listings only
- Real-time availability and pricing
- User reviews and ratings

### 🚕 Transportation Management
- Inner-city and intercity transport booking
- Official pricing database
- Licensed transport providers only
- Real-time tracking and updates

### 🎭 Tours & Activities
- Curated Egyptian experiences
- Expert-guided tours
- Activity booking system
- Cultural information and tips

### 📚 Travel Information Hub
- Visa requirements and processes
- Links to Egyptian government authorities
- Safety guidelines for tourists
- Cultural etiquette guides

### 💳 Unified Booking System
- All-in-one itinerary builder
- Secure payment processing
- Multi-language support
- 24/7 customer support

## Technology Stack

### Backend
- **Framework**: Django 4.2.7
- **API**: Django REST Framework
- **Database**: PostgreSQL (Production), SQLite (Development)
- **Language**: Python 3.10+

### Frontend
- React.js (to be integrated)
- Responsive design
- Multi-language support

### Integrations
- Booking.com API
- Expedia API
- Payment Gateway (Stripe, Fawry)
- Google Maps API
